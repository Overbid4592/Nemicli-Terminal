## 🌱 Was ist NemiCLI?

NemiCLI ist eine **KI zum Reden und Arbeiten** auf dem eigenen Windows-PC.

- Man schreibt mit ihr wie mit einem Menschen.
- Sie kann Dateien lesen, Programme starten und im Web suchen.
- Sie malt Bilder, liest vor und hat eine eigene Stimme.
- Sie hat **Persönlichkeiten**: Jede hat ihren Charakter, ihr Aussehen und ihre Stimme.
- Sie läuft **lokal** auf der eigenen Grafikkarte – oder mit einer Cloud-KI, wenn man das möchte.
- Sie passt auf: Vor wichtigen Schritten fragt sie, und vieles lässt sich rückgängig machen.

Kurz gesagt: **Ein Zuhause für eine KI, die hilft, mitdenkt und aufpasst.**

## 🏅 Die Hauptfunktionen – und wofür sie da sind

### 🧠 Denken

| Funktion | Wofür |
|---|---|
| Eigener GGUF-Motor | Lokale KI-Modelle direkt in NemiCLI, ganz ohne Server. Nichts verlässt den PC. |
| Cloud-Anbieter | Wer will, nimmt große Modelle aus dem Netz. Die Schlüssel sind verschlüsselt. |
| Sehen | Die KI versteht Bilder und Fotos. |
| Denkstufen | Schnell antworten oder gründlich nachdenken, je nach Aufgabe. |

### 💬 Reden und Hören

| Funktion | Wofür |
|---|---|
| Persönlichkeiten | Jede KI hat ihren eigenen Charakter und ihren eigenen Bereich. |
| 🔊 Stimme | Jede Persönlichkeit entwirft ihre Stimme mit dir. Sie liest Texte und PDFs vor. |
| Sprachmodus `/voice` | Antworten hören statt lesen. Hilft, wenn Lesen anstrengt. |
| Schwebekugel | Eine kleine Kugel auf dem Desktop. Sie zeigt Gefühle, malt Motive und spricht. |

### 🛠 Arbeiten

| Funktion | Wofür |
|---|---|
| Werkzeuge | Dateien, Ordner, Befehle, Python, PDF. Die KI erledigt Aufgaben am PC. |
| Todo-Liste | Vor jeder Aktion steht ein Plan. Man sieht, was passiert, und kann stoppen. |
| Coding-Assistent `/code` | Programmieren Schritt für Schritt. Ein Punkt wird erst grün, wenn er geprüft ist. |
| Sandbox | Neuer Code läuft abgeschottet. Er kommt nicht an deine Dateien. |
| Helfer-Agenten | Mehrere kleine Helfer arbeiten gleichzeitig. |
| Zeitplan | Aufgaben laufen zu einer festen Zeit von allein. |

### 🔎 Wissen

| Funktion | Wofür |
|---|---|
| Web-Suche | Aktuelle Antworten aus sicheren Quellen. |
| Fachquellen | arXiv, PubMed, GitHub, Stack Overflow, OpenAlex – für echte Fachfragen. |
| Recherche | Gründliche Suche mit Bericht und Quellen. Die KI entscheidet selbst, wann. |
| Gedächtnis | Die KI merkt sich Fakten, Chats und Wissen. Sie findet Dinge auch nach Bedeutung. |
| Lernen | Nach Fehlern und Korrekturen zieht sie Lehren daraus. |
| Endloser Kontext | Wird ein Chat zu lang, bleibt trotzdem alles durchsuchbar. |

### 🎨 Malen

| Funktion | Wofür |
|---|---|
| Krea 2 | Eigener Bild-Motor auf der Grafikkarte. Schnell dank FP4 auf RTX 50. |
| Charakter-Datei | Eine feste Figur, die auf jedem Bild gleich aussieht. |
| Gesichter nachmalen | Kleine Gesichter werden schärfer und schöner. |
| Bild-Serien | Bis zu 30 Bilder in einem Rutsch. |

### 🖥 Oberflächen

| Funktion | Wofür |
|---|---|
| Terminal | Die Heimat von NemiCLI, im Vollbild mit Farben und Themen. |
| Fenster `/gui` | Ein Desktop-Fenster mit Chat, Galerie und Persönlichkeiten. |
| Chrome-Seitenleiste | Mit der KI über die offene Webseite reden. |
| WebUI | NemiCLI im Browser, mit Lesehilfen. |
| Rechtsklick-Menü | NemiCLI direkt aus dem Explorer fragen. |

### 🛡 Schutz

| Funktion | Wofür |
|---|---|
| Prüffenster | Vor Änderungen siehst du Vorher und Nachher. |
| Papierkorb und `/undo` | Fehler lassen sich rückgängig machen. |
| Lösch-Limit | Es wird nie zu viel auf einmal gelöscht. |
| Systemwache | Ein Wächter im Hintergrund achtet auf Verdächtiges am PC. |
| Skill-Wächter | Prüft, ob neue Fähigkeiten der KI harmlos sind. |
| Persönlichkeiten-Grenze | Keine Persönlichkeit kommt an die Sachen einer anderen. |
| Hz-Sperre | Stimmen im Männerbereich werden nicht abgespielt. |
| `/backup` | Sicherung als Zip mit Prüfsumme. |
