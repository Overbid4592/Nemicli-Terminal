# Contributing to NemiCLI

Contributions are welcome.

Before submitting changes:

- Keep changes focused and understandable.
- Do not include personal information, API keys, tokens, passwords, or other secrets.
- Explain clearly what your change does.
- Test your changes before submitting them.
- Follow `SECURITY.md` for security-related issues.

For larger changes, please open an issue first so the idea can be discussed before implementation.
