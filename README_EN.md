# NemiCLI

NemiCLI is an AI agent for Windows focused on terminal workflows, tool use, long-term memory, RAG, local and cloud language models, and image generation.

It is built in Python and combines a terminal-based AI assistant with controlled tool access, persistent memory, workspace isolation, browser integration, local services, and image workflows.

## Highlights

- AI agent for Windows terminal workflows
- Python-based architecture
- Local and cloud LLM support
- Long-term memory with embeddings and RAG
- Controlled file and PowerShell tool access
- Workspace mode with project-scoped access
- Action logging and confirmation for changes
- Sub-agents for delegated tasks
- Vision and image generation support
- ComfyUI and Forge/A1111 integration
- Browser and Windows context-menu integration
- Accessibility features for easier reading

## Typical use cases

NemiCLI can act as a terminal assistant, coding helper, research agent, memory-enabled AI companion, local AI frontend, automation tool, and image-generation controller.
