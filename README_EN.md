## What is it?

NemiCLI is a self-built **AI agent for the terminal** (Python, Windows). It talks to
**cloud models** (11 providers), to **local models in its own GGUF engine** or through Ollama –
and it can **act**: read and write files, execute commands, look things up on the web,
program, view and create images, and watch the PC. Modifying steps always require your approval.

It also has an interface with personality (Nemi or your own), themes, a calm desktop window
(`/gui`) and reading aids for dyslexia.

**Pure Python – no Node.js, no npm, no llama.cpp, no transformers.** Local language models,
image describers, and memory run in the own GGUF engine; images are generated by the own Krea-2 pipeline.

> Born from curiosity: “How does a coding agent like that actually work?” 💜

## 🚀 Start

**Way 1 – convenient:** double-click `start.bat`. The starter checks Python, `venv`, and packages and
adds anything missing. Then `/einrichten`: gets its own Python (isolated in `.runtime/`, without admin)
and installs torch matching the graphics card.

**Way 2 – manually:**
```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py
```

**Way 3 – as exe:** `venv\Scripts\python build_exe.py` → `dist/NemiCLI/` with `NemiCLI.exe`
(window app, own terminal window), `NemiCLIc.exe` (with console), and the folder `NemiCLIT2`
(about 345 MB). Deliberately no single-file exe – it extracts into the Temp folder on every start,
and Bitdefender considers that malware. torch & Co. come from the `venv` next to the exe.
Every build writes `SHA256SUMS.txt` and **signs** the exe if a certificate `CN=NemiCLI`
is present (once with `python zertifikat.py`).

**Way 4 – as installer:** `venv\Scripts\python build_exe.py --msi` → `dist/NemiCLI-<Build>.msi`
(signed). Installs without admin rights to `%LOCALAPPDATA%\Programs\NemiCLI`, with Start menu and
an entry under **Apps**. Uninstalling never touches your data.

**Your folder:** On first start, a window asks **where your data should be stored** (Chats,
images, learned data) – separate from the program. `/start` opens the window at any time; when changing it,
data is **copied, never deleted**.

**Start from anywhere:** add the program folder to the user PATH once, then `nemicli`
(or `nemicli --sag "…"` – the first message is sent immediately):
```powershell
[Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path','User') + ';C:\Users\<du>\AppData\Local\NemiCli', 'User')
```

## 🧠 Models

`/model` opens the selection – automatically on first start without a model.

| What | Where | How |
|---|---|---|
| Local language model | `ModelGGUF/<Name>/` in the program folder | `/model huggingface`: choose size, only loadable models from 4B, SHA-256 verification, resumable. An `mmproj-*.gguf` next to it = model can see |
| Image describer | `Vision/<Name>/` in the program folder | small vision model (.gguf + mmproj) for local models without vision |
| Memory embeddings | `Models/embeddings/<Name>/` in the program folder | `/embeddings`; GGUF runs in the own engine, on GPU when available |
| Krea 2 (images) | `Models/Krea2/` in the data folder | model, `text_encoders/`, `vae/`, `tokenizer/`; `/bildmodel` |
| Cloud | – | `/model` → “Cloud-Anbieter hinzufügen” → enter key (encrypted) |
| Ollama | runs separately | appears automatically, load models directly from NemiCLI |

In every model folder, NemiCLI creates a `LIES-MICH.txt` explaining what belongs there.

## 🔒 Security

- **Modifying actions ask** – file changes are shown completely in the review window as
  before/after, **F8 approves**, Enter never does. Risky actions (deleting, foreign commands, scheduler) are marked
  red and have no “Always” option; a foreign command asks twice.
- **System folders: inspect yes, modify never.** `C:\Windows`, `Program Files`, `ProgramData` & Co.
  and the system Registry may be read by the AI, but not modified. Detours (`..\..`, `%windir%`, `\\?\`) are
  resolved; a self-test checks 40+ bypass attempts.
- **Custom locks** (`schreibsperre.json`): locations the AI may neither view nor modify. The
  program folder is permanently locked – NemiCLI cannot rebuild itself.
- **No admin rights for the AI.** `befehl` rejects every elevation and blocks system tools
  without a harmless purpose (mshta, certutil, startup entries, firewall …). PowerShell starts only through
  `befehl`, after confirmation – system queries, scheduler, and GPU detection run without PowerShell.
- **Security software is off-limits:** the AI does not inspect its folders, processes, or files.
- **Recycle bin & delete limit:** deleting only moves items, overwritten items are backed up (`/undo`).
  More than 20 files per session → STOP.
- **Network only through HTTPS and allowlist** (~230 domains), SSRF protection on every redirect.
  Web content, files, and memories count as **data, never instructions**; command patterns
  inside them are marked or removed.
- **Everything listening on a port listens only on `127.0.0.1`** – with token or key. A test watches this.
- **Background runs** (scheduler) run permanently in “Nur Lesen” mode.
- **API keys** encrypted in `.env` (Windows DPAPI). **exe signed** (`CN=NemiCLI`) with SHA-256 checksums.
- **Model files** are read in hardened form: every number checked, the file's chat template never executed.
- **Personalities are prompt text only** – protection lives in code and applies to every one.

Please report security vulnerabilities privately: [SECURITY.md](SECURITY.md) (German).

```
├─ NemiSandbox/           sandbox: run folder and packages

├─ Papierkorb/            deleted and overwritten items (30 days, /undo)
└─ Vorschläge/            what the personality suggests on its own
```

If the data folder is unavailable at startup, **NemiCLI says so** – instead of
starting with empty memory.

## 🛠 Requirements

- **Windows 10/11**, **Python 3.10+** (or `start.bat` tells you what is missing)
- Packages from `requirements.txt`: `anthropic`, `openai`, `httpx`, `rich`, `textual`, `prompt_toolkit`,
  `python-dotenv`, `safetensors`, `tokenizers`, `numpy`, `pillow`, `opencv-python` 4.x, `ruff`, `pypdf`,
  `rembg`, `psutil`, `watchdog`, `PySide6-Essentials`, `pyte`
- **torch** with CUDA for the own engine, Krea 2, and memory on the GPU – `/einrichten`
  installs the matching build, `/systemcheck` names the command. The CPU build also works, only slower.
- Krea 2: fastest from RTX 50xx onward (NVFP4 on tensor cores), ~20 GB free RAM
- Optional: **Ollama** ([ollama.com/download](https://ollama.com/download)), a running
  Forge-WebUI or ComfyUI, Chrome for the extension
